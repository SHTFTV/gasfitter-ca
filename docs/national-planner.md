# National planner

Gasfitter.ca owns the national presentation; BeeWarm remains a separate local service tool. This static browser-only route preserves the existing site architecture. Includes all provinces/territories and record-only gas/pressure/meter fields in JSON/text/print exports. No utility capacity certification, pressure-drop calculation or pipe sizing is implemented. Existing branch, load, longest-run and restore validation are retained. No plan/image uploads or automatic enquiry sending. Province selection does not select code tables or a qualified contractor.
